```

├── index.html          ← اللعبة الكاملة (HTML + CSS + JS)

├── oberge-logo.png     ← شعار المطعم (ضع الملف هنا)
├── icons/
│   ├── icon-192.png    ← أيقونة PWA (192×192)
│   └── icon-512.png    ← أيقونة PWA (512×512)

```

## خطوات النشر

### 1. أضف شعار المطعم
- انسخ ملف الشعار إلى نفس مجلد `index.html`
- سمّه: `oberge-logo.png`
- إذا لم يوجد، ستظهر أيقونة بديلة تلقائياً

### 2. أنشئ أيقونات PWA
- مجلد `icons/` يحتوي على:
  - `icon-192.png` (192×192 px)
  - `icon-512.png` (512×512 px)
- يمكن استخدام أي أداة تحويل صورة

### 3. رفع الملفات على الاستضافة
رفع جميع الملفات على أي استضافة تدعم HTTPS:
- **cPanel**: رفع عبر File Manager إلى `public_html`
- **Netlify**: سحب وإفلات المجلد مباشرة
- **Vercel**: `vercel deploy`
- **Firebase**: `firebase deploy`

### 4. إنشاء QR Code
بعد النشر، اذهب إلى أي موقع QR مثل:
- https://qr.io
- https://www.qrcode-monkey.com

أدخل رابط اللعبة واطبع QR Code على:
- طاولات المطعم
- قائمة الطعام
- شاشة المطعم

## التخصيص

### تغيير أرقام الهواتف
في `index.html` ابحث عن:
```
06 7666 551 | Salama: 06 5953 095
```

### تغيير عدد الثواني
```javascript
STATE.timeLeft = 60; // غيّر إلى الرقم المطلوب
```

### إضافة أطباق جديدة
في مصفوفة `menuItems` أضف:
```javascript
{ icon:'🍽️', ar:'اسم الطبق', en:'Dish Name', desc:'الوصف', cta:'السعر' }
```

### تغيير عتبة المكافآت
```javascript
if (STATE.goals === 20 && !STATE.milestone20) { ... } // غيّر 20
if (STATE.goals === 30 && !STATE.milestone30) { ... } // غيّر 30
```

## المعلومات التقنية

- **التقنيات**: HTML5 Canvas, CSS3, Vanilla JS
- **PWA**: نعم (manifest + service worker)
- **حفظ البيانات**: localStorage (محلي على الجهاز)
- **الخطوط**: Google Fonts (Tajawal + Bebas Neue)
- **الحجم**: ~55 KB (ملف واحد بدون مكتبات خارجية)
- **المتصفحات**: Chrome, Safari, Firefox, Edge
